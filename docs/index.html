Choosing the Right APK Architecture

Every release includes split APKs per CPU architecture alongside a `SHA256SUMS.txt` checksum manifest.

Filename Suffix Recommended For Details
*-arm64-v8a.apk Modern Android Phones (2018+) Recommended for 99% of physical smartphones. Compact (~38 MB) and native 64-bit speed.
*-universal.apk Universal Compatibility Includes all CPU architectures in one file (~96 MB). Safe fallback for any device.
*-armeabi-v7a.apk Older 32-bit Phones For legacy 32-bit ARM devices manufactured prior to 2017.
*-x86_64.apk Emulators & Intel Tablets For desktop Android emulators (Android Studio, Waydroid) and x86_64 hardware.

Release Candidates (`-rcN-<commit>`) & Field Testing

Before promoting a major update to Stable, we publish Release Candidates tagged with the exact short commit hash (for example v0.8.0-rc1-6697d76 or client-v1.3.0-rc1-6697d76), inspired by the MeshCore lusofw firmware workflow. Stable installations only prompt for verified stable releases by default, while field testers can install `-rc` builds from the Releases page and report feedback on the issue tracker.
